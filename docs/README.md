## [1] About the Project

`🌟 당신의 평범한 하루가 사진 한 장으로 기억될 수 있도록`

1. **사진으로 쓰는 하루 일기**: 사진과 함께 하루의 감정을 기록하고 안전하게 저장합니다.
2. **커뮤니티 공간**: 사용자 간 하루의 일상을 공유할 수 있도록 소통의 장 제공
